# 21game
The 21 Number Game is a simple command-line Python game played between a user and the computer. Players take turns saying consecutive numbers from 1 to 21, and each player can say 1 to 3 numbers in a single turn. The player who is forced to say 21 loses the game.
How the Game Works
1. The game starts from number 1.
2. The player and computer take turns.
3. On each turn, a player can enter or speak:
1 number
2 consecutive numbers
or 3 consecutive numbers
4. Numbers must follow the correct sequence.
5. Whoever says 21 loses.
